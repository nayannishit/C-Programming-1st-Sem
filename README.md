# C Programming — 1st Semester

Welcome to my C Programming repository! 👋

This repository contains my C programming practice programs as a first-semester B.Tech Computer Science and Engineering student. I am using this repository to learn programming fundamentals, improve my problem-solving skills, and track my progress.

## 📚 Programs List

### Hello, GitHub!
A simple C program to print a greeting message on the screen.

### Program 01: C Data Types
A C program to demonstrate basic data types in C.

### Program 02: Area of a Circle
A C program to calculate the area of a circle using its radius.

### Program 03: Average of Three Numbers
A C program to calculate the average of three numbers.

### Program 04: Swapping Two Numbers Using a Temporary Variable
A C program to swap two numbers using a temporary variable.

### Program 05: Single-Line and Multi-Line Comments
A C program to demonstrate single-line and multi-line comments.

### Program 06: Operator Precedence and Associativity
A C program to demonstrate the order of execution of operators in expressions.

### Program 07: Even or Odd Number
A C program to check whether a given number is even or odd.

### Program 08: Positive, Negative, or Zero
A C program to determine whether a given number is positive, negative, or zero.

### Program 09: Menu-Driven Calculator Using Switch-Case
A C program that performs arithmetic operations using a menu-driven calculator until the user chooses to exit.

### Program 10: Multiplication Table Using Loops
A C program to generate the multiplication table of a number using `for`, `while`, and `do-while` loops.

### Program 11: Arrays and Memory Addresses
A C program to accept integer, float, and character array elements and display their values and memory addresses.

### Program 12: Sum of One-Dimensional Array Elements
A C program to calculate the sum of all elements in a one-dimensional array.

### Program 13: Matrix Addition Using a Two-Dimensional Array
A C program to read two matrices of the same order, add them, and display the resultant matrix.

### Program 14: Factorial Using a User-Defined Function
A C program to calculate the factorial of a given non-negative integer using a user-defined function.

### Program 15: Area of a Triangle Using Four Types of User-Defined Functions

A C program to calculate the area of a triangle using four types of user-defined functions:

- No arguments and no return value
- Arguments but no return value
- No arguments but returns a value
- Arguments and returns a value
